Лабораторная работа №2: Камера и освещение

Цель лабораторной работы:

В  этой  лабораторной  работе  вам  предстоит  реализовать

“камеру”  с

возможностью  ее  перемещения  и  освещение  по  модели  Блинн-Фонга  с

использованием множества типов источников света.

Требования:

Вы должны использовать Vulkan, GLFW и ImGUI. Стартовый код уже всё это

содержит, но если хотите попробовать без него, то я похвалю за отвагу!

P.S. Если хотите программировать на Direct3D под Windows, то используйте

именно Direct3D 12, потому что он концептуально похож на Vulkan.

Условие:

●  Используйте  код  предыдущей  лабораторной  работы,  чтобы  внести

динамическое освещение на сцену с вашим объектом по варианту

●  Программа  должна  работать  в  реальном  времени,  с  возможностью

взаимодействия с камерой (позиция, поворот, угол обзора), источниками

освещения  (позиция,  цвет  +  интенсивность,  и  другие  параметры,

уникальные  для  соответствующего  типа  источника),  а  также  моделями

(параметры материала: альбедо, цвет блика, коэффициент блика) через

пользовательский интерфейс

●  У  вершин,  помимо  позиции,  должен  быть  задан  атрибут  нормали.

Нормали вершин рисуемого объекта нужно генерировать процедурно

●  Для  каждого  источника  света  должна  быть  реализована  модель  Блинн-

Фонга во фрагментном шейдере

●  Для точечного и прожекторного источника нужно реализовать затухание

по закону обратных квадратов

●  Для  прожекторного  источника  нужно  реализовать  мягкие

края

освещаемой  области.  Для  этого  нужно  задать  параметры  внешнего  и

внутреннего углов

●  Для доступа к массивам памяти для точечных и прожекторных источников

света  используйте  storage  буферы,  чтобы  не  задавать  максимальное

количество элементов массива в шейдере

В  этой  работе  дается  простор  для  креатива:  можете  добавить  больше

объектов, пол и стены, а также анимировать источники света или прикрепить их

к  объектам.  Чем  интереснее  смотрится  сцена,  тем  аутентичнее  будет

рассматриваться ваша работа!

Оценивание:

•  На оценку 3 нужно выполнить базовое задание ниже без выполненных

дополнительных заданий

•  На оценку 4 нужно выполнить базовое задание с первыми тремя

дополнительными заданиями.

•  На оценку 5 нужно выполнить все дополнительные задания.

Базовое задание:

Для  объекта  из  предыдущей  лабораторной  работы  вашего  варианта

необходимо сделать только его отрисовку относительно камеры с единственным

направленным  источником  освещения.  Все  параметры  камеры,  источника

освещения и параметры материала по модели освещения Блинн-Фонга, а также

рассеянный

свет

(ambient

light)

должны

быть

изменяемыми

из

пользовательского интерфейса ImGUI.

Дополнительные задания:

1.  Разделите внешние данные на два набора дескрипторов: один для сцены,

другой  для  модели.  В  наборе  дескрипторов  для  сцены  будут  находится

uniform  buffer  –  структура  с  параметрами  сцены  и  общими  для  всех

объектов данными (матрица view-projection и пр.), а также storage буферы

–  массивы  источников  освещения.  В  наборе  дескрипторов  для  модели

будут  находится  данные  о  матрице  трансформации  и  параметры

матриала

2.  Реализуйте  освещение  по  модели  Блинн-Фонга  массивом  точечных

источников освещения из storage буфера, учитывайте затухание по закону

обратных  квадратов.  В

графическом  интерфейсе  должна  быть

реализована  возможность  добавления  и  удаления  источников  с

изменением их параметров

3.  Реализуйте освещение по модели Блинн-Фонга массивом прожекторных

источников освещения из storage буфера, учитывайте затухание по закону

обратных  квадратов,  края  освещаемой  области  должны  быть  мягкими,

если  внешний  угол  больше  внутреннего.  В  графическом  интерфейсе

должна  быть  реализована  возможность  добавления  и  удаления

источников с изменением их параметров

4.  (На  оценку  5)  Реализуйте  визуализацию  источников  освещения  с

возможностью  показа/скрытия  в  пользовательском  интерфейсе:  яркий(-

ая)  куб/сфера  с  цветом  источника  освещения  для  точечного  и

прожекторного  источника.  Дополнительно  для  прожекторного  источника

нарисовать  направление  и  угол  (можно  просто  нарисовать  белыми

линиями конус). Фигуры визуализации должны иметь постоянный цвет и

не должны освещаться по модели Блинн-Фонга
