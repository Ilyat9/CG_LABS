# Лабораторная работа №2 — Камера и освещение

И. А. Афромеев, М8О-303БВ-24. Вариант 3 — параллелепипед.
Номер: `((3 - 1) % 12) + 1 = 3`. Во второй работе используется объект из ЛР №1.

Реализация на C++20, Vulkan, GLFW и ImGui. Первая лабораторная остаётся в корне репозитория; в этой папке находится самостоятельная вторая работа.

## Сборка и запуск

Нужны C++20-компилятор, CMake >= 3.20, Ninja, Vulkan SDK с `glslc`.
На macOS SDK должен включать MoltenVK. Зависимости GLFW, vk-bootstrap, VMA и ImGui загружаются CMake при первой конфигурации; требуется интернет.

Из корня репозитория:

```bash
cd lab2
cmake --preset debug
cmake --build build-debug --parallel
./build-debug/lab2-camera-lighting
```

Запускайте из `lab2`: пути к скомпилированным шейдерам относительные.
На этом компьютере SDK установлен в `/usr/local`, дополнительные переменные окружения не нужны.
Если используется Homebrew Vulkan, путь к MoltenVK должен быть доступен загрузчику Vulkan.

Проверки:

```bash
ctest --test-dir build-debug --output-on-failure
```

## Управление

- Camera: положение, yaw, pitch, FOV; перспективная/ортографическая проекция.
- W/A/S/D — перемещение в горизонтальной плоскости, Q/E — вниз/вверх; правая кнопка мыши — осмотр. Управление действует вне захваченного интерфейсом ввода. При текстовом вводе нужна английская раскладка.
- Ambient and directional: фоновое освещение, направление, цвет и интенсивность направленного света.
- Materials and transforms: положение, вращение, масштаб, альбедо, цвет и показатель блика каждой модели.
- Point lights / Spot lights: добавление, удаление и параметры каждого источника.
- Inner / Outer angle: **полууглы** конуса в градусах, `0 <= inner <= outer <= 80`. При равных значениях граница жёсткая.
- Show light markers and cones: показывает/скрывает маркеры, не меняя освещение.
- Animate lights: вращает точечные источники вокруг мировой оси Y.
- Directional only / Points / Spot: заменяют массивы источников демонстрационными настройками.

## Выполненные требования

| Требование | Реализация |
|---|---|
| Базовое задание | Камера и один направленный свет, модель Блинн–Фонга во фрагментном шейдере, все параметры в ImGui |
| Доп. 1 | Set 0: Scene UBO и два SSBO; Set 1: матрица модели и материал |
| Доп. 2 | Изменяемый массив точечных источников, затухание `1 / max(d², 0.01)` |
| Доп. 3 | Изменяемый массив прожекторов, то же затухание и `smoothstep` между углами |
| Доп. 4 | Неосвещаемые цветные маркеры и белые внутренний/внешний конусы |

Нормали генерируются через векторное произведение рёбер: 24 вершины на шесть плоских граней, 36 индексов. При неравномерном масштабе используется обратная транспонированная матрица нормалей.
Размеры SSBO задаются во время выполнения; GLSL использует `.length()`, фиксированных массивов источников в шейдере нет. Пустой массив представлен нулевой записью с нулевой интенсивностью. Перезапись, освобождение и обновление дескрипторов выполняются после fence предыдущего кадра. Число объектов визуализации ограничено размером пула дескрипторов и памятью устройства.

Затухание ограничено только в радиусе 0.1 от источника для устранения сингулярности. Нулевое направление заменяется на `(0,-1,0)`. Маркеры имеют постоянный цвет; конусы показывают углы и направление, а не физическую дальность. Тени не входят в реализацию.

## Структура

- `source/application.cpp` — сцена, интерфейс, дескрипторы, SSBO, запись команд.

- `shaders/shape.vert`, `shaders/shape.frag` — преобразования и освещение.
- `tests/math_tests.cpp` — проверки камеры, нормалей, граничных углов и глубины Vulkan.
- `report/303_Афромеев_Лаба2.pdf` — отчёт для сдачи.
- `report/303_Афромеев_Лаба2.docx` — редактируемый отчёт по шаблону.

Проверено: сборка Debug на macOS, CTest, три режима света в окне приложения, удаление последнего источника каждого типа, повторное добавление, показ/скрытие маркеров. Скриншоты реального приложения находятся в `report/`.
